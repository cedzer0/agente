# Agents, à poil

Ce que je comprends **vraiment** des agents IA — pas de la paraphrase de doc, mais des
use cases que j'ai montés, du code qui tourne, des architectures que j'ai branchées, et
les résultats en image.

Chaque article suit le même fil : **concept → use case → architecture → code → résultats**.
Chaque article a été relu et validé avant publication. Rien n'est publié tant que je n'ai
pas compris et validé ce qu'il raconte.
